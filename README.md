# 就労移行支援事業所向けポータルサイト
## 1. 目的
勤怠管理や作品・書類提出の効率化ならびに連絡事項の共有の効率化

## 2. ターゲット
就労移行支援事業所の利用者

## 3. できること
- ユーザー検証機能(エラー検出機能付き)：フリーアドレスでデバイスが共用の場合もあり、ユーザー検証機能を設置。入力ミスや不正アクセスをガードするエラー検出機能付き。<br>
- 作品・応募書類添削のための提出：スタッフによる添削を効率よく行うため、提出フォームを設置。<br>
- スタッフからのメッセージの表示：面談やシフト提出など、提出期限や大まかな日程が決まっているお知らせもここで表示。

## 4. こだわり
- 利用者に優しいデザイン：文字サイズやカレンダーの色使いなどにおいて、直感的に分かりやすいデザインを心掛けている。<br>
- ログインする楽しさも入れている：占い機能を設けることで、毎日継続してログインする楽しさを利用者に提供している。

## 5. 得られた知見
過去にこういったポータルサイトの制作経験はあったものの、今回は就労移行支援事業所の利用者さんがターゲットということもあり、「<strong>そもそも毎日ログインしてくれるのか</strong>」という懸念点も考えられた。それだけに、「ただ便利なだけ」ではない、<strong>利用者心理に基づいた利用者に向けたユーザー体験の実装の重要さ</strong>を学習できた。
